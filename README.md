# ⛴️ Toronto Ferry Capacity & Operational Efficiency Analytics

An end-to-end data analytics and machine learning project for analyzing Toronto Island Ferry ticket activity, capacity utilization, operational pressure, demand patterns, and operational efficiency.

The project transforms historical ferry ticket sales and redemption records into actionable operational insights using **Python, statistical analysis, interactive Streamlit dashboards, K-Means clustering, and Isolation Forest anomaly detection**.

---

##  Project Overview

Ferry operations experience highly variable demand across different hours, days, seasons, and years. A fixed operating schedule can therefore result in both:

- High-pressure periods where demand exceeds normal operating levels
- Low-utilization periods where resources remain underused

This project analyzes historical Toronto Island Ferry ticket activity to identify:

- Capacity utilization patterns
- High-pressure and congestion periods
- Sustained low-activity periods
- Seasonal and hourly demand patterns
- High-cost, low-utilization operating windows
- Distinct operational activity regimes
- Unusual or anomalous activity intervals

The final output is an interactive **Streamlit analytical portal** designed to convert historical ticket data into practical operational decision-support insights.

---

##  Objectives

The main objectives of this project are to:

1. Analyze historical ferry ticket sales and redemption activity.
2. Engineer operational features from raw ticket records.
3. Measure capacity utilization and operational pressure.
4. Identify recurring peak and idle periods.
5. Analyze hourly, weekly, seasonal, and yearly demand patterns.
6. Segment ferry activity into meaningful operational regimes using K-Means.
7. Detect unusual activity using Isolation Forest.
8. Identify recurring high-cost, low-utilization time windows.
9. Provide actionable recommendations for capacity and staffing planning.
10. Present the complete analysis through an interactive Streamlit dashboard.
